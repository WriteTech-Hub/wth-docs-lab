[01] The path

Three levels. One path.

Start where you are. Each level closes with a capstone deliverable you can add to your portfolio.

01
Beginner

Foundations

Clear writing, document types, style guides, working with SMEs, and responsible AI use. Build enough foundation to write something useful for a real reader.

  • Google Technical Writing courses
  • Diataxis framework
  • Style guides (Google, Microsoft)
  • Working with subject matter experts
  • Git, GitHub and open source
Start here →
02
Intermediate

Practice & Delivery

Information architecture, docs-as-code, API documentation, and quality systems. Build portfolio-ready work used in active projects.

  • Information architecture
  • Docs-as-code with GitHub
  • API documentation
  • Vale prose linting
  • AI-assisted editing workflows
Level up →
03
Advanced

Systems & Scale

Content strategy, governance, measurement, cross-functional influence, and AI at programme level. Own documentation across an entire product.

  • Content strategy & governance
  • Documentation metrics
  • Cross-functional influence
  • RAG & agentic AI systems
  • CI/CD for documentation
Go deep →

[02] The method

How the library works

  1. 1

    Pick your level

    Start at Beginner if you are new. Move up when you complete the capstone.

  2. 2

    Study and practise

    Read the resources, then do the exercises. The exercises are where learning happens.

  3. 3

    Build your capstone

    Each level ends with a deliverable. Build it and add it to your portfolio.

  4. 4

    Share and grow

    Post your work in the WriteTech Hub community and get feedback.
